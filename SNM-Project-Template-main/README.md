**📝 Simple Notes Management (SNM)**

## 📖 About the Project

**Simple Notes Management (SNM)** is a web-based application developed using Python Flask that helps users manage their notes and organize information through an easy-to-use interface.

This project was developed as part of my practical learning at **Codegnan Institute, Visakhapatnam**, where I gained hands-on experience in building web applications, implementing backend functionality, and understanding the workflow of a Flask-based project.
